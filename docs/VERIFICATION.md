# Verification

## Recorded acceptance

| Scope | Evidence | What it establishes |
| --- | --- | --- |
| Real frontend Devnet | [Report](../web/tests/evidence/frontend-devnet-report.md), [raw evidence](../web/tests/evidence/frontend-devnet.json) | 25 feature groups, five launches, 97 finalized application transactions, and 17 mobile routes |
| Devnet program deployment | [Deployment](../contracts/tests/evidence/devnet-deployment.json), [build manifest](../contracts/build-manifest.json) | Release program IDs, recorded bytecode checks, and initialized platform |
| Contract adversarial acceptance | [Summary](../contracts/tests/evidence/security-summary.json), [local lifecycle](../contracts/tests/evidence/lifecycle.json) | Compiled-SBF execution, authorization/identity checks, arithmetic, rollback, and replay rejection |
| Local validator | [RPC evidence](../contracts/tests/evidence/rpc-smoke.json) | Genuine validator transactions and ProgramData bootstrap |
| Rust backend | [Acceptance](../backend/tests/acceptance/report.json), [fixtures](../backend/tests/fixtures) | Recorded native parity, persistence, local HTTP lifecycle, and bounded operational checks |

Evidence records the environment and scope of a particular run. Read it together with the corresponding source and build manifest. Recorded results are not promises of current RPC availability or production certification.

## Frontend checks

```bash
npm ci
npm run repo:check
npm run check
npm run web:test
npm run build
npm run web:transport:test
npx playwright install chromium
npm run web:onboarding:test
node web/tests/wallet-network.cjs
```

The onboarding check is read-only browser acceptance. Set `DEPTHGUARD_WEB_ORIGIN` to select a running application; it defaults to the public Devnet app. The wallet network fixture never signs transactions.

## Independent SBF regression

```bash
python3 backend/scripts/fetch-fixtures.py
npm test
npm run test:proof
```

These tests load checksum-verified official programs into isolated LiteSVM instances and use ephemeral local signers. They do not send public-network transactions. Results generated by the continuity regression are ignored under `proof/results/`.

## Rust and Anchor

```bash
npm run backend:build
# Use a dedicated test database with database-creation privileges.
npm run backend:test
npm run backend:proof
npm run backend:e2e
contracts/scripts/install-agave.sh
npm run contracts:build
npm run contracts:test
npm run contracts:security
```

Rust database tests and HTTP lifecycle tests require a private, dedicated test database. Contract tests build their own compiled programs; program and operator keypairs remain ignored. See [contract reproduction](../contracts/README.md#reproduction) for prerequisites.

CI checks formatting, Clippy, dependency audits, typed API regeneration, frontend builds, native parity, and local program-backed lifecycles. It does not deploy to Devnet or Mainnet.

## Real Devnet browser acceptance

```bash
npm run web:devnet:preflight
npm run web:devnet:frontend
```

The full frontend harness signs real Devnet transactions and consumes test SOL. It requires an already configured release, running services, private RPC settings, and funded operator/test keypairs. Follow [the harness instructions](../web/tests/FRONTEND-DEVNET.md); it is not a zero-configuration CI smoke test.

The harness uses real wallet keypairs through an automated Wallet Standard adapter. Browser extension approval flows, sustained load, fault recovery under worker interruption, external metadata hosting, asset-quote adapters, and independent audit require additional acceptance. Mainnet remains blocked.
